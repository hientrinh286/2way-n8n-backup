Encrypted backups for a self-hosted n8n installation.

2WAY n8n Backup is a personal setup that helps the owner preserve a local Docker-based n8n instance and store encrypted backup archives in the owner's Google Drive account.

Read our Privacy Policy → Project on GitHub

How the backup process works

The n8n application remains self-hosted on the owner's Windows computer. Google Drive is used only as an off-site destination for encrypted backup files.

01 / LOCAL

Create a local backup

A backup archive is created from the owner's n8n Docker data volume on the local Windows computer.

02 / ENCRYPT

Encrypt with Rclone Crypt

Rclone Crypt encrypts the backup archive and its filename before it is uploaded to cloud storage.

03 / STORE & RESTORE

Use personal Google Drive

The encrypted archive is stored in the owner's Google Drive account. The owner can download and decrypt a backup to recover it.

Important: This is an informational page for an owner-operated backup workflow, not a public backup service. It does not provide public uploads, account registration, or access to 2WAY English student records. The owner controls backup scheduling, retention, access, and recovery.

Google Drive access

The desktop OAuth connection is used by Rclone to manage the owner's backup files in Google Drive. Authorization is granted through Google's sign-in and consent screen. See the Privacy Policy for the types of data processed and how the backup works.
