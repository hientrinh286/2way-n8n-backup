Privacy Policy

Effective date: October 22, 2026 · Last updated: October 22, 2026

At a glance: 2WAY n8n Backup is a personal, owner-operated backup setup. Rclone is used on the owner's Windows computer to upload encrypted n8n backup archives to the owner's Google Drive. This informational website does not collect backup files or authenticate users.

1. Purpose and scope

This policy describes how the personal 2WAY n8n Backup setup accesses and uses Google Drive data. It is not a public software-as-a-service product. It is not the 2WAY English student or parent portal.

2. Data accessed

When the owner signs into Google through Rclone, Google grants access according to the permissions shown on the OAuth consent screen. The access is used for creating, uploading, listing, downloading, and managing backup files in the owner's Google Drive account.

Local n8n backup archives may contain workflow definitions, application configuration, the SQLite database, and encrypted n8n credentials. The exact contents depend on the owner's n8n setup. The informational website itself does not receive or process those archives.

3. How data is used and protected

  • The owner's backup process creates an archive on the local Windows computer.
  • Rclone Crypt is used to encrypt backup content and filenames before uploading to Google Drive.
  • The encrypted archives are stored in the Google Drive account selected by the owner.
  • Rclone's Google OAuth authorization is stored locally in the owner's Rclone configuration. Encryption passwords and recovery credentials must be retained securely by the owner.
  • Backup archives are accessed or restored only at the owner's direction or through automation the owner explicitly configures.

Encryption protects file contents before upload, but Google may still process cloud-storage metadata such as file sizes and timestamps under Google's own policies. No claim is made that the system has undergone an independent security audit.

4. Sharing and external services

Google Drive provides storage for encrypted archives, and Google provides OAuth authentication. GitHub Pages hosts this public informational website. The site contains no embedded analytics scripts, advertising pixels, account-creation forms, or file-upload controls. Google and GitHub may process service-related logs and metadata under their own terms and privacy policies.

The owner does not use backup data for advertising or sell backup data to third parties. Backup data is not sent to the public GitHub repository or to GitHub Pages.

5. Retention and deletion

Backup files remain in the owner's Google Drive until the owner deletes them or activates a retention policy. Retention and deletion are controlled by the owner, not by this website. Revoking Google access stops future authorized Rclone operations; it does not automatically remove backup files already stored in Google Drive.

6. Security and restoration responsibilities

The owner is responsible for protecting the local computer, Google account, Rclone configuration, encryption passwords, and recovery keys. To restore from a backup, the owner needs both the encrypted archive and the corresponding decryption information.

7. Changes to this policy

This policy may be updated if the backup workflow, permissions, or handling of Google data changes. The latest version will appear on this page with an updated date.

8. Contact

For questions about this personal backup setup or its data handling, contact the owner through the project's GitHub repository.

This policy describes the intended owner-operated setup and must be kept aligned with the actual permissions and backup configuration in use.
